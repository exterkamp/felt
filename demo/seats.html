Two seats

One game, three copies of it: a server that decides, and two players' tables that only show. A tap on your own card asks the server to play it; 150 ms later the server stamps it for a tick far enough ahead, and 150 ms after that both tables apply it on that very tick. Every copy reaches the same state, which the fingerprints below show. Both boards run on one engine, painting from one set of art.
